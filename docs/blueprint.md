# **App Name**: Bahpura Mandir

## Core Features:

- Bilingual Interface: Display content in both Hindi and English, with user-selectable language preference stored in local storage.
- Single-Page Layout: Implement a smooth-scrolling single-page design with dedicated sections for About, Events, Seva (Community Service), Donations, Gallery, and Contact.
- Donation System: Enable online donations via UPI, bank account, and QR code, linking to a dedicated donation section.
- Contact Form: Provide a contact form for inquiries and messages, integrated with Google Maps for temple location.

## Style Guidelines:

- Primary color: Saffron (#F4B400) to evoke spirituality and tradition.
- Background color: Pale yellow (#FAF2D6), a desaturated version of saffron, to support the light scheme.
- Accent color: Gold (#D4AF37) to highlight important elements like donation buttons.
- Hindi font: 'Mukta', a sans-serif typeface to render Devanagari script in a clear, readable manner. English Font: 'Poppins' for a contemporary, precise feel.
- Centered layout with ample whitespace for a clean, uncluttered aesthetic.
- Gentle fade-in animations for section transitions and smooth scrolling for enhanced user experience.
- Use simple, culturally relevant icons (e.g., diya, temple) to enhance visual communication.
